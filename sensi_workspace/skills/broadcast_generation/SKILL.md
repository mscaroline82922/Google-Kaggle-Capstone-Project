# Skill: Broadcast Generation (Media Optimization Flow)
Procedural memory pattern for processing imagery via Gemini 2.5/3 Pro and generating public safety updates.

## Step Workflow:
1. Parse satellite delta payloads from MCP Server tools.
2. Formulate textual structural evaluation parameters.
3. Call Veo video generation chains to output localized public instructions.

## Expected Inputs:
- `zone`: string (e.g., "Sector 7")
- `urgency`: string (e.g., "CRITICAL")
- `telemetry`: JSON string containing structural metrics.

## Expected Outputs:
- 1080p evacuation visuals (simulated path).
- Signed textual alert package.
